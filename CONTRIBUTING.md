# Contributing

Use Node ^24.15.0 or >=26 and pnpm 12.14.0. Run `pnpm install && pnpm build` before examples or tests that consume the package exports. `pnpm check` covers formatting, lint, strict TypeScript, 100% per-file adapter coverage and the packed package. `pnpm bench` prints measured form timings. Do not invent numbers from those timings.

Use focused branches and Conventional Commits. Never add attribution trailers. Never publish, push, deploy or create remote resources as part of local development.
